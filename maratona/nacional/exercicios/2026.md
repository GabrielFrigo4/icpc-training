| Problema | Nome                | Tema Principal                     | Técnica / Algoritmo                                                                                         |     Complexidade      |  Dificuldade  |
| :------: | :------------------ | :--------------------------------- | :---------------------------------------------------------------------------------------------------------- | :-------------------: | :-----------: |
|  **A**   | Antonia's Ants      | Ad-Hoc / Construtivos (Interativo) | Coloração Construtiva Periódica ($K = 2$) + Reconstrução Linear por Transições Determinísticas              |    $O(N + \sum M)$    | Médio-Difícil |
|  **B**   | Between Two Cameras | Estruturas de Dados / Geometria    | Ordenação Angular (Produto Vetorial em Inteiros) + Contagem Ponderada de Inversões com Fenwick Tree (BIT)   |     $O(N \log N)$     |     Fácil     |
|  **C**   | Clumsy Courier      | Combinatória                       | Independência de Eixos (Intercalação Binomial) + Princípio da Reflexão com Duas Barreiras (ou DP 1D)        |  $O(R + C + U + L)$   |     Médio     |
|  **D**   | Divine Lights       | Ad-Hoc / Simulação                 | Manutenção de Paridade Global (Lazy Flip / Invariante de Contagem)                                          |        $O(N)$         |  Muito Fácil  |
|  **E**   | Escape Plan         | Teoria dos Grafos / Árvores        | DFS Bottom-Up + Algoritmo Guloso em Árvore (Emparelhamento de Folhas com Ancestrais)                        |        $O(N)$         |     Médio     |
|  **F**   | Father's Footsteps  | Ad-Hoc / Algoritmos Gulosos        | Compressão de Blocos Consecutivos (RLE) + Cálculo de Contribuição (Delta) por Elemento                      |        $O(N)$         |     Fácil     |
|  **G**   | Gratitude Loop      | Ad-Hoc / Simulação                 | Simulação Direta com Vetores de Estado                                                                      |      $O(N + M)$       |  Muito Fácil  |
|  **H**   | Hazel's Harvest     | Estruturas de Dados                | Sweep-line Offline por Altura + Fenwick Tree / Segment Tree + Busca Binária ($K$-ésimo Menor)               | $O((N + Q) \log^2 N)$ | Médio-Difícil |
|  **I**   | Imprecise Location  | Geometria Computacional / Árvores  | Sweep-line com Árvore Balanceada (`std::set`) para Árvore de Contenção de Retângulos + LCA (Binary Lifting) |  $O((N + Q) \log N)$  |     Médio     |
|  **J**   | Just Four Pieces    | Matemática / Ad-Hoc                | Análise Algébrica de Restrições / Busca em Vizinhança Constante                                             |        $O(1)$         |  Muito Fácil  |
|  **K**   | Kayaking            | Programação Dinâmica               | DP de Perfil por Coluna (Broken Profile DP em Grade $2 \times N$ com Conectividade e Ciclos)                |       $O(N^2)$        |    Difícil    |
|  **L**   | Lookout Towers      | Árvores / Programação Dinâmica     | DP em Árvore (Distância Mínima e Contagem de Pares) ou BFS Multi-Fonte                                      |        $O(N)$         |     Fácil     |
|  **M**   | Moving Mountains    | Programação Dinâmica / Gulosos     | Transformação de Caminho de Dyck em Vetor Não-Decrescente + Guloso / DP da Direita para a Esquerda          |        $O(N)$         | Médio-Difícil |
